Orient a new developer on ShiftFrontend.

1. Read `CLAUDE.md` (root) — project overview, stack, conventions
2. Read `docs/ARCHITECTURE.md` — routing map and user registration flow
3. Read `docs/CODEBASE_AUDIT.md` §3 (dead files) and §5 (priority tasks)
4. Read `tasks/todo.md` — what is planned or in progress
5. Read `tasks/lessons.md` — mistakes already made, rules to follow
6. Run: `npm install` (if node_modules missing)
7. Run: `npm run dev` — confirm dev server starts on http://localhost:3000

Report:
- What is the project and what does it do?
- What pages exist and what does each one do?
- What is currently in progress?
- What are the top 3 most important things to know before writing any code?
- Any blockers (missing .env.local, build errors, etc.)
